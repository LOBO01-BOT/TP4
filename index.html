Ejercicio 10: Inferencia en KB - El Enigma del Unicornio

Punto 3 del TP Anterior (R&N 7.2)

«Si el unicornio es un animal mitológico, entonces es inmortal, pero si no es mitológico, entonces es un mamífero mortal. Si el unicornio es inmortal o mamífero, entonces tiene cuernos. El unicornio es mágico si tiene cuernos.»

1. Mito ⇒ Inmortal
2. ¬Mito ⇒ Mamifero ∧ ¬Inmortal
3. (Inmortal ∨ Mamifero) ⇒ Cuernos
4. Cuernos ⇒ Magico

A partir de esta Base de Conocimiento, deduce qué preguntas pueden responderse con certeza formal mediante inferencia lógica:

1. ¿Se puede demostrar que el unicornio es mitológico? ¿KB ⊨ Mito?
2. ¿Se puede demostrar que el unicornio tiene cuernos? ¿KB ⊨ Cuernos?
3. ¿Se puede demostrar que el unicornio es mágico? ¿KB ⊨ Magico?
